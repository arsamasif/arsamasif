### Hi, I'm Arsam

I'm a pipeline developer in Toronto. I write the Python, Maya and USD tools
that get artists' work from scene to screen. I've spent ten years in VFX and
animation, most recently as Senior Pipeline Developer and Lead Support
Developer at Pixomondo on House of the Dragon, Star Trek and The Boys.

Credits and write-ups of the studio pipelines I built are on
[arsamali.com](https://www.arsamali.com). The tools below are ones I've put
out in the open.
